## Introduction

This project is taken part at the Jodrell Bank Centre for Astrophysics, University of Manchester, as part of a global collaboration with scholars from Durham, Groginen, and Shanghai. Through observing radio-quiet quasars (RQQs) in the distant Universe through gravitational lensing, we aim to set constraints to the mass profile of the foreground galaxies with statistical modelling to the datasets. 

This README focuses on the technical parts of the project and how these skills demonstrates data analysis and pipeline development. The Python scripts can be found in the folder `scripts/` and will be discussed in this introductory file.
